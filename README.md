 RT Management Frontend (React)

 Requirements

* Node.js >= 18
* npm / yarn
* Git

---

 1. Clone Repository

```bash
git clone https://github.com/dewintanur/rt_appfe.git
cd rt_appfe
```

---

 2. Install Dependency

```bash
npm install
```

---

 3. Konfigurasi API

Buka file:

```bash
src/api.js
```

Pastikan:

```js
baseURL: "http://127.0.0.1:8000/api"
```

---

## 🚀 4. Jalankan Aplikasi

```bash
npm start
```

Akses:
http://localhost:3000
